These expose availability only. Browser code imports only the pure reminder-schedule parser, separated from the server handler without changing its exported legacy contract. Reads/saves snapshot account/token scalar values, check server ledger before/after, match exact response environment/enrollment, validate saved/effective schedules and exact revision/value acknowledgement, and bound settings responses to 4096 bytes with redirect refusal and a 30-second HTTP abort signal.

# アプリ単位の再登録・購入世代の隔離（ローカル試作）

account-epochs-prototype.sqlは本番マイグレーションではありません。共有Authを残したまま、おうちメンテの登録世代をランダムUUIDで区別します。明示的な再登録は新しい本人確認済みセッションにだけ結び付け、古いセッションと購入世代は新しい登録に使用できません。古い削除要求が遅れて到着しても、新しい世代を無効にしません。

PGliteの独立DBで、ブラウザー権限による登録拒否、旧セッション拒否、旧購入世代拒否、他ユーザーの維持、再登録失敗時のロールバックを確認しました。共有Authのユーザーは削除しません。

未完了: 実Authのsession_id検証と最近の再認証、登録API、Web/nativeのセッション継続、RLSと全RPC、購入APIとApple通知への世代接続、旧ファイルと個人情報の削除、マーカーと取引情報の正当な保持期間、競合実行試験。セッションUUIDはクライアント入力を信頼しません。閉鎖後のログイン・トークン更新で自動再登録しません。

Appleのアカウント削除要件を満たしたとは扱いません。既存account_access試作とも未接続で、本番に適用・有効化しません。本人や家族のデータをテストに使いません。

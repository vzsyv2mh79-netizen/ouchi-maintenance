# iPhone版の保存済み記録表示

クラウドで最後に取得した記録を、端末のCaches領域にアカウントUUID付きで保存します。ファイルは完全保護・バックアップ除外を設定し、アクセストークンやパスワードを含めません。10MiBを超えるコピーは拒否します。ログアウトでコピーを削除し、別アカウントのコピーは読み込みません。

保存済みログインを復元した起動時、同じアカウントのコピーがあれば先に表示し、クラウド読み込みを試みます。取得成功で置き換え、認証拒否401/403でコピーと表示を破棄します。通信失敗時には保存済み記録の表示であることを示します。端末コピーは共有権限・ログイン有効性・購入済み利用権の証明ではありません。

編集は引き続き認証済みAPIで行い、成功を確認した内容だけを保存します。オフライン編集キュー・競合解消は未実装です。CachesはOSに削除される場合があり、バックアップや確実な保存先ではありません。書き出しには従来のバックアップ機能を使います。

OfflineSmokeはアカウント不一致・サイズ上限・認証情報を含めないコピーを合成データで確認します。実iPhoneの機内モード起動、再接続、ログアウト後ファイル削除、端末ロック保護、家族共有の権限変更後の挙動は別途検証が必要です。全オフライン対応完了とは扱いません。

SnapshotStorageSmokeで実際のテスト用ファイルを読み書きし、別アカウントの拒否・削除・繰り返し削除を確認します。MacではiOSのファイル保護とバックアップ除外の実効性を確認できないため、それらは実端末で別途確認します。iOS版の完全保護・バックアップ除外設定は維持しています。
